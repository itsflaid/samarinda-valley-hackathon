# SANITAIR

SANITAIR adalah platform health-tech preventif berbasis early awareness (kesadaran dini) yang dirancang khusus untuk memitigasi risiko wabah penyakit bawaan air (waterborne diseases) di tengah Status Siaga Darurat Bencana Kekeringan Provinsi Kalimantan Timur 2026. Berakar dari refleksi sejarah kelam Wabah Kolera Samarinda 1991, platform ini hadir sebagai solusi regional terukur untuk melindungi masyarakat—mulai dari krisis air perkotaan di Samarinda dan Balikpapan, hingga wilayah pesisir dan pulau terluar yang terisolasi seperti Maratua, Berau.
